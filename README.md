## 🌟 应用核心特性

- **高保真原生音频引擎**：基于 Android 原生 Media3 / ExoPlayer 与 MediaPlayer 双引擎，支持无损 Hi-Res 音频播放。
- **本地与流媒体融合**：支持本地全格式音频扫描解析，支持网易云与 Bilibili 在线音源及双语/逐字歌词。
- **沉浸式现代美学设计**：
  - 封面双主色弥散微光流动背景；
  - 半透明悬浮毛玻璃卡片（Glassmorphism）与圆润胶囊组件；
  - 状态栏歌词（魅族 Flyme 协议）与原生桌面小部件；
  - 原生全屏锁屏播放器与通知栏控制中心。
- **纯净无扰**：无广告、无推广、专注纯粹的高品质音乐享受。
